About UANet Architecture

IEEE TGRS 2024 Publication

Title: UANet: An Uncertainty-Aware Network for Building Extraction From Remote Sensing Images

Authors: Jiepan Li, Wei He, Weinan Cao, Liangpei Zhang, Hongyan Zhang

Honors: 2024 IEEE GRSS Data Fusion Contest Double-Track Champion

1. Multi-scale Boundary-enhanced Dilation Convolution (MBDC)

Enriches spatial boundary representations across multiple receptive fields to preserve sharp roof edges and geometric corners.

2. Progressive Information Guidance Module (PIGM)

Guides high-level semantic flow from deep encoder stages down to lower stages, preventing false detections in shadowed regions.

3. Uncertainty Rank Algorithm (URA) & Fusion Module (UAFM)

Quantifies pixel-wise prediction uncertainty using $0.5 - |0.5 - \text{Sigmoid}(M)|$. The UAFM actively fuses multi-scale features prioritizing high-confidence regions while iteratively correcting uncertain roof borders.
